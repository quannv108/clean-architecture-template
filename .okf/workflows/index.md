Repeatable procedures, with the exact commands and the steps that are easy to get wrong.

# Subdirectories

* [engineering](engineering/index.md) - Building, running and verifying the code - the exact commands.
* [process](process/index.md) - How work moves - branching, pull requests, and growing the template into a product.

Procedures a human must perform *outside* the repository — configuring secrets, creating accounts, anything
an agent cannot do — will live in `runbooks/`, not here.
