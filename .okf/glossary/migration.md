# Migration

Generated by `dotnet ef migrations add`, stored in `src/Infrastructure/Database/Migrations`, applied in
order.

Two things specific to this repository: the command needs `--output-dir Database/Migrations` and
`-- --environment Migration`, and the generated classes must be changed from `public partial` to
**`internal partial`**.

See [Add an EF Core Migration](../workflows/engineering/add-ef-migration.md).
